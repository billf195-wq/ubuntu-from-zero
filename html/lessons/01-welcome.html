Welcome & what Ubuntu is

A friendly intro to Ubuntu for Windows users — what it is, how it feels familiar, and what is different.

Steps

  1. You just installed (or are about to use) Ubuntu — a free operating system, like Windows or macOS, but built on Linux.
  2. Ubuntu is made by Canonical and a huge community. Version numbers like 24.04 mean April 2024; 26.04 means April 2026. The .04 releases are long-term support (LTS) — good for everyday use.
  3. Think of Ubuntu as: a desktop you can click around, install apps, browse the web, and do office work — same goals as Windows, different tools under the hood.

Ubuntu vs Windows — the short version

  • Desktop: Ubuntu uses GNOME by default (Activities overview, dock on the left). Windows uses the taskbar and Start menu. Different layout, same idea: launch apps and switch windows.
  • Apps: You install from App Center / Software, or Flatpak, or the terminal. No need to hunt random .exe download sites for most things.
  • Updates: One Software Updater (or a short terminal command) keeps the system and many apps current.
  • Files: Your stuff lives under /home/yourname/ (like C:\Users\yourname). Drive letters (C:, D:) are not how Linux thinks — disks are “mounted” as folders.
  • Permissions: Admin tasks ask for your password (sudo). There is no separate “Administrator” account you log into daily.
Tip You do not need to memorize everything. This guide goes step by step. Click around the desktop — you will not break Ubuntu by exploring Settings.

What you will learn here

Seventeen short lessons: desktop basics → Files and apps → terminal safely → backups and troubleshooting → a bit of gaming and customization. Take them in order if you are brand new.
