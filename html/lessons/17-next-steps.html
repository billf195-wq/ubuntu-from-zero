Next steps / learning path

Where to go after these 17 lessons — practice projects and trusted resources.

Steps

  1. Practice: install one app from App Center, one Flatpak, and run sudo apt update && sudo apt upgrade once this week.
  2. Make a Timeshift snapshot (or copy Documents to USB) before your next big change.
  3. Skim the official Ubuntu desktop docs and ask questions on Ask Ubuntu — search first, then post clearly.
  4. Optional next skills: basic bash scripting, git, Docker, or a programming language — only when the desktop feels boringly reliable.

Suggested path

  1. Daily comfort: Files, updates, browser, backups
  2. Terminal literacy: navigate, edit a text file with nano, read man pages (man ls)
  3. Packaging literacy: apt vs Flatpak vs Snap
  4. Hobby track: gaming (Steam), creative apps, or coding tools
