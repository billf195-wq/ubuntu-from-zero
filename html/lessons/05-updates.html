Updates

Keep Ubuntu healthy with Software Updater and a gentle apt intro.

Steps

  1. When Ubuntu notifies you, open Software Updater. Review the list → Install Now → enter password → restart if asked.
  2. You can also open Software Updater anytime from Activities.
  3. Optional terminal way (same idea): open Terminal and run the two commands below, one at a time.
sudo apt update
sudo apt upgrade

update refreshes the list of available packages. upgrade installs newer versions. You will be asked for your password — characters do not echo as you type. That is normal.

Do not paste random “fix my Ubuntu” scripts from the internet. Stick to Updater or these two commands until you are comfortable.
After upgrades If a kernel or graphics update landed, a reboot is healthy. Save your work first.
