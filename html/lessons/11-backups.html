Backups

Timeshift for system snapshots and a simple “copy important files” habit.

Steps

  1. Decide what matters: Documents, Photos, browser bookmarks export, project folders.
  2. Simple file backup: plug in a USB drive or use a cloud folder; copy Home folders you care about. Schedule a calendar reminder monthly.
  3. Timeshift (popular on Ubuntu): install from App Center or apt, then create rsync/snapshot backups before big upgrades. Restore if an update goes wrong.
  4. Test a restore once — a backup you never tested is a wish, not a plan.
sudo apt install timeshift

After install, search Activities for Timeshift. Prefer snapshots on a separate disk when possible.

Note Timeshift is for system restore points; it is not a full replacement for copying your personal photos off the machine.
