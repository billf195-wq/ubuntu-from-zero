Troubleshooting checklist

No internet, stuck updates, and slow boot — calm first steps.

Steps

  1. Stay calm. Write down what changed last (new app, update, cable).
  2. No internet: toggle airplane mode, reconnect Wi‑Fi, try Ethernet, reboot the router, check Settings → Network.
  3. Stuck update: wait a few minutes; check if Software Updater is waiting for a password behind another window. Reboot and retry. Avoid force-killing dpkg unless a trusted guide says so.
  4. Slow boot: note whether it is firmware, disk, or login. Free disk space in Home; disable unneeded startup apps in Settings → Apps → Startup.
  • Reproduce the problem once more — same every time?
  • Reboot once (save work first)
  • Check cables / Wi‑Fi password / airplane mode
  • Free space: Files → Home → Properties; aim for several GB free
  • Recent change: uninstall the last new app and retest
  • Updates: run Software Updater
  • Search the exact error text + “Ubuntu 24.04” or “26.04”
Logs (later) When you are ready, journalctl -b -p err shows serious errors from this boot — advanced, but good to know exists.
