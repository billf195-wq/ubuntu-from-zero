Terminal basics

pwd, ls, cd, and copy-paste — enough to follow guides without fear.

Steps

  1. Open Terminal: Ctrl+Alt+T or search “Terminal”.
  2. Type pwd and press Enter — print working directory (where you are).
  3. Type ls — list files. Try ls -la for details and hidden files.
  4. Type cd Downloads to enter Downloads (if it exists). cd .. goes up one folder. cd alone returns to Home.
  5. Copy text from a guide: select → Ctrl+Shift+C in Terminal to copy; Ctrl+Shift+V to paste. Or use the right-click menu.

Tip Tab completion is magic: type the first letters of a folder name and press Tab. The shell fills in the rest when it is unique.
Read before you run Never run a command you do not understand if it includes rm -rf, dd, or pipes to sh from a random website.
